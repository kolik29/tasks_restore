# Список тикетов из Git

```sh
npm install
npm run build
npm start -- --path /path/to/repository --date 2026-05-01
npm start -- --path /path/to/repository --date 2026-05-01 --user na.kulikov,kolik29 --output avaclinic.csv
```

Обязательны `--path` и `--date`. Дата в формате `YYYY-MM-DD`, включительно от полуночи в локальном часовом поясе машины; используется дата коммита (committer date). Необязательный `--user` принимает имена или email через запятую. Пробелы вокруг значений удаляются, поиск подстроки выполняется без учёта регистра. Достаточно совпадения с любым из значений; без `--user` выбираются все авторы. Пустые значения запрещены.

Читается локально доступная история веток, тегов и HEAD без выполнения fetch. В CSV включаются тикеты из начала сообщений коммитов, прошедших фильтры даты и автора. Поддерживается префикс `Pull request #123:`. Существование отдельной ветки задачи не требуется: задачи из удалённых после слияния веток сохраняются, если их коммиты остались в истории.

Номера только из названий веток не добавляются. На каждый тикет сохраняется одна строка с данными самого раннего найденного коммита. Строки сортируются по номеру тикета.

Колонки CSV: `ticket`, `parent`, `hash`, `date`, `title`, `user`, `release`. Дата записывается в ISO 8601 UTC, `title` — сообщение без номеров и префикса conventional commit, `user` — имя автора.

Если в сообщении несколько номеров, первый — родитель остальных. Если в самом раннем коммите родитель не указан, берётся первая найденная связь по хронологии других коммитов. При отсутствии связи `parent` пустой.

`release` — первая ветка с окончанием `-stage`, содержащая выбранный hash, после сортировки названий с учётом чисел. Проверяются локальные и remote-tracking ветки, одинаковые названия объединяются. Если веток нет — `ХФ`. Cherry-pick с другим hash не считается совпадением.

Необязательный `--output` задаёт путь CSV относительно рабочей папки или абсолютный путь. По умолчанию используется `tickets.csv`. Папка назначения должна существовать. Файл в UTF-8 с BOM перезаписывается при повторном запуске. Если задач нет, записывается только заголовок.

Классы — в `src/classes`, интерфейсы — в отдельных файлах `src/interfaces`. Проверки: `npm run typecheck` и `npm test`.
